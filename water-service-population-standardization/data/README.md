# Aggregate results

The `aggregates/` directory contains 20 tables covering observed and standardized WSQS results, 41-threshold cumulative distributions, overlap diagnostics, working uncertainty intervals and sensitivity analyses. The [data dictionary](../docs/DATA_DICTIONARY.md) defines the table fields and units.

The CDF table agrees with 205 source-specific values and 41 piped–groundwater differences in the E23 result register at reported precision. See [Numerical provenance](../docs/PROVENANCE.md) for the comparisons with saved computational results.

Individual survey records and detailed Figure S1 category-level data are not included. Aggregate results are released under [CC BY 4.0](../LICENSE-DATA), apart from verbatim questionnaire wording in SI Table S2, which follows the survey-instrument terms; see [license coverage](../LICENSES.md). The [questionnaire repository](https://github.com/Osman-Lab-Stanford-University/water-service-survey-2025) provides the English and Tamil survey instruments.

The six E27–E28 CSVs cover learner-specific standardized means, conditional out-of-fold prediction comparisons, training-only HGBR tuning frequencies and working AIPW variability. See [outcome-model sensitivity](../docs/OUTCOME_MODEL_SENSITIVITY.md).
